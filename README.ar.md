# copyme — مهارة لـ Claude Code

بتحوّل ملف موقع مستخرج بأداة **Enrichr** لواجهة أمامية مكتوبة من الصفر بـ **React وNext.js وTailwind**، مطابقة
للأصل في التصميم والتجاوب مع الشاشات والتفاعلات والحركة — وبتثبت ده بصور جنب بعض واختبارات حقيقية وقياس
الحركة لقطة بلقطة.

> استخدمها على مواقعك، أو مواقع عندك إذن تعيد بناءها، أو للتعلّم. المهارة بتكتب الكود كله من الصفر، وبتغيّر الاسم
> والشعار والرسومات والنصوص بحاجات أصلية، وبتختم بقسم يوضّح إيه اللي ما ينفعش يتنسخ بالظبط من غير إذن صاحبه.

## بتعمل إيه

1. **تحلّل** فولدر Enrichr: الألوان والمقاسات وهيكل الصفحة ونقاط التجاوب وحالات المرور والضغط.
2. **تصوّر الموقع الحقيقي** لكل الصفحات (لأن Enrichr بيجيب الصفحة اللي اتفتحت بس)، وتفتح اللوحات الجانبية
   والقوايم والنوافذ وصفحات التفاصيل.
3. **تبني** كل الصفحات والنوافذ بمحتوى أصلي.
4. **تقارن** أماكن العناصر والصور على أربع مقاسات شاشة وتصلّح الفروق.
5. **تطابق الحركة** بقياس حركات الموقع الحقيقي في كل لقطة وتحويلها لمنحنيات حركة بنفس التوقيت.
6. **تراجع السرعة** (تقليب ناعم ~٦٠ لقطة في الثانية) وتكتب ملف شرح للمشروع.

ومعمولة علشان تخلص أسرع وتصرف توكنز أقل من غير ما تقلّ دقة التطابق: ملخص واحد صغير للملف المستخرج بدل قراية
الملفات الخام، ومقارنة صور بالأرقام بتشاور على الأماكن المختلفة بالظبط، وقيم الحركة بتتاخد من كود الموقع نفسه لو
فيه مكتبة حركة، ومشروع بداية جاهز، وفحص واحد في الآخر. وأنت اللي بتشغّل Enrichr بنفسك وبتدّي المهارة الملف
الجاهز، هي مش بتنصّبه ولا بتشغّله.

## المتطلبات

- Claude Code
- Node.js 20 أو أحدث، وPython 3 مع مكتبة Pillow، ومتصفح Google Chrome
- ملف مستخرج بـ Enrichr للصفحة المطلوبة
- أداتين للتحكم في المتصفح (لقياس الحركة):

```bash
claude mcp add --scope user chrome-devtools -- npx -y chrome-devtools-mcp@latest
claude mcp add --scope user playwright -- npx -y @playwright/mcp@latest
```

## التركيب

انسخ فولدر `copyme` لفولدر المهارات بتاعك:

```bash
cp -R copyme ~/.claude/skills/
npm i --prefix ~/.claude/skills/copyme/scripts
python3 -m pip install --user pillow
```

وابدأ جلسة جديدة عشان المهارة والأدوات يتحمّلوا.

## الاستخدام

```
/copyme ~/Downloads/enrichr-extract-1234/
```

أو اكتب `/copyme` واسحب فولدر Enrichr في المحادثة. المشروع بيتعمل في فولدر `rebuild` جوه فولدر Enrichr، إلا لو
طلبت مكان تاني.
